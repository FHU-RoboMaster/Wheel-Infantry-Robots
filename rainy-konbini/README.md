# 雨夜の街角 ─ 星見マート

一个可直接打开的三渲二雨夜便利店街角微缩模型。整个场景由 Three.js 程序化建模，没有使用 Blender，也没有外部贴图或模型文件。

## 观看方式

直接双击打开 **`index.html`** 即可。模型完全内联在这一个文件里，无需联网或启动服务器。

- 鼠标左键拖拽：绕模型旋转
- 鼠标滚轮 / 触控板双指：缩放
- 触屏拖拽：旋转；双指捏合：缩放
- 没有操作提示、按钮或其他 UI，窗口会自适应完整显示正方形底座

推荐使用桌面浏览器、1600×1000 或更大窗口观看。移动端会自动拉远镜头以保持整个底座可见。

## 场景内容

- 正方形收藏底座、黄铜包边与实体铭牌
- 日式便利店「ほしみマート」：转角玻璃幕墙、自动门、招牌灯箱、立式灯箱、雨棚与檐下筒灯
- 店内：饮料冷柜、便当/饭团货架、零食货架、杂志架、收银台、关东煮、咖啡机、热食柜、海报、吊牌、后场门与储物柜
- 店外：自动贩卖机、自行车、伞架、分类垃圾桶、公告栏、停车位、斑马线、止まれ路面字、排水沟、护栏、路牌、电线杆与电线、远处信号灯、小巷入口与红灯笼、空调外机、后场服务区
- 雨夜氛围：持续降雨、玻璃雨痕、屋檐滴水、地面积水与涟漪、湿路面反光、自动门间歇开合、招牌轻微闪烁、信号灯循环、店内蒸汽、流浪猫尾巴的小幅动作

## 技术说明

- Three.js r186，MeshToonMaterial + 反向壳描边 + UnrealBloom + 自定义色调/暗角/颗粒后期
- 完全程序化的 Canvas 纹理和标牌，没有外部资源请求
- 雨水使用动态 LineSegments；积水涟漪、屋檐滴水、玻璃雨痕均为实时动画
- 性能模式：静态阴影、半分辨率 Bloom、2× MSAA、按窗口比例自动取景
- 场景始终完整保留在正方形底座上，相机极角受限，不会穿到模型下方

## 重新构建（可选）

```bash
npm install
npm run build
```

构建产物会覆盖 `index.html`。也可以运行 `npm run serve` 后通过本地端口观看。

源码结构：

- `src/main.js` — 相机、后期、交互、自适应取景
- `src/world.js` — 底座、街道、店面外壳、外立面与灯光
- `src/interior.js` — 便利店内部陈设
- `src/street.js` — 街道道具、小巷、猫咪与环境动画
- `src/effects.js` — 降雨、涟漪、滴水、玻璃雨痕
- `src/textures.js` / `src/kit.js` — 程序化贴图、灯笼材质与建模工具
