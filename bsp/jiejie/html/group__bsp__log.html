日志快捷宏

使用固定等级调用 BSPLogWrite()。

参数
[in]tag为非 NULL、NUL 结尾的标签，允许空串；format 为非 NULL 的 printf 格式串。 两者仅在调用期间借用，可变参数须与 format 匹配。 启用时返回 BSPLogWrite() 的结果；关闭时展开为 ((void)0)。
注解
启用时每个参数求值一次，即使记录随后被等级过滤。 关闭时参数不求值，不输出日志，也不更新已保存状态。 需要始终获取返回状态时，请直接调用 BSPLogWrite()。
警告
启用时遵守 BSPLogWrite() 的上下文、栈空间及格式要求。

详细描述

提供带标签的 RTT 记录和任务本地错误查询。

自从
1.0.1

通道 0 用于文本，通道 1 用于 JScope，通道 2 用于预留数据。

状态保存约定
除查询接口另有说明外，操作结果保存在启动状态或当前任务状态中；OK 清除旧错误， PENDING 保留旧状态。ISR 调用不更新状态，FreeRTOS TLS 槽位 0 由本模块独占。

返回

返回值

◆ BSPLogWrite()

err_t BSPLogWrite ( bsp_log_level_t level,
const char * tag,
const char * format,
... )

按指定等级格式化并提交带标签的日志记录。

参数
[in]level日志等级，范围为 TRACE（0）至 FATAL（5）。
[in]tag借用的非空、NUL 结尾标签；允许为空串，在调用期间有效。
[in]format借用的非空 printf 格式串，在调用期间有效。
[in]...按 format 要求的顺序和类型提供格式化参数。
返回
日志提交状态，具体取值如下。
返回值
OK记录提交成功。
PENDING记录被等级过滤。
ARG_ERR日志等级非法。
PTR_NULLtag 或 format 为空。
INIT_ERR日志尚未初始化。
STATE_ERR上下文被拒绝。
FAILED格式化失败。
SIZE_ERR记录过长。
NO_BUFFRTT 空间不足。
NOT_SUPPORT日志已关闭。
注解
使用私有栈缓冲区，并通过 RTT 内部锁执行一次写入。 记录格式为“[LEVEL][tag] 正文”，末尾为 CRLF，最多提交 511 字节。 过滤在参数和初始化检查之后、上下文检查之前执行。 PENDING 直接跳过记录，不入队且不改变已保存错误状态。 其他结果更新启动状态或当前任务状态；ISR 结果不会更新状态。
警告
未被过滤的写入拒绝 ISR、中断屏蔽和调度器挂起上下文。 512 字节行缓冲区及 libc 格式化需要调用方提供足够栈空间。 格式化参数必须与 format 匹配；libc 格式化可能分配内存。 初始化后通道 0 必须保持 SEGGER_RTT_MODE_NO_BLOCK_SKIP 模式。

◆ Float2StrN()

int Float2StrN ( char * str,
size_t size,
float va )

将有限浮点数转换为固定三位小数的字符串。

参数
[out]str借用的非空调用方缓冲区，最多接收 size 字节（包括 NUL）。
[in]size缓冲区容量，单位为字节，至少为 1，包括 NUL 结束符空间。
[in]va有限输入值，取整后的 va * 1000 位于 [-2^63, 2^63) 内。
返回
成功时返回完整结果字符数（不含 NUL）；返回值大于等于 size 表示截断。 str 为 NULL、size 为 0、输入非有限或越界、snprintf 失败时返回 -1。
注解
以 0.001 精度取整，中点向远离零方向舍入，取整后的零输出为 0.000。 size 大于 0 且 str 非 NULL 时，即使失败，缓冲区也以 NUL 结尾。 整数部分按 32 位十进制分组以支持 newlib-nano；不读取或修改日志错误状态。
警告
要求 str 指向至少 size 字节的可写缓冲区，调用上下文满足 libc 格式化要求。
