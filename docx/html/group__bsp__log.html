详细描述

提供带标签的 RTT 记录和任务本地错误查询。

自从
1.0.1

通道 0 用于文本，通道 1 用于 JScope，通道 2 用于预留数据。

状态保存约定
除查询接口另有说明外，操作结果保存在启动状态或当前任务状态中；OK 清除旧错误， PENDING 保留旧状态。ISR 调用不更新状态，本模块独占配置指定的 FreeRTOS TLS 槽位。

◆ BSPLogClear()

err_t BSPLogClear ( void )

通过 RTT 通道 0 提交终端清屏控制序列。

返回
控制序列提交状态，具体取值如下。
返回值
OK清屏序列提交成功。
INIT_ERR日志尚未初始化。
STATE_ERR上下文被拒绝或释放日志互斥锁失败。
NO_BUFFRTT 空间不足。

注解

警告
拒绝 ISR、中断屏蔽和调度器挂起上下文；通道 0 必须保持 SEGGER_RTT_MODE_NO_BLOCK_SKIP 模式。

◆ BSPLogInit()

err_t BSPLogInit ( void )

固定小数输出的精度、缩放系数及整数分组参数。

缩放系数等于 10 的小数位数次方，分组基数等于 10 的分组位数次方。 分组后分别使用 uint32_t 输出，兼容 newlib-nano 的整数格式化。

注解
修改位数时必须同步调整对应的缩放系数或分组基数。

在调度器启动前初始化 RTT 终端、数据及预留通道。

返回

返回值
OK初始化成功或重复成功初始化。
STATE_ERR不在启动阶段线程上下文。
INIT_ERRRTT 配置或静态互斥锁创建失败。

◆ BSPLogWrite()

err_t BSPLogWrite ( bsp_log_level_t level,
const char * tag,
const char * format,
... )

按指定等级格式化并提交带标签的日志记录。

参数
[in]level日志等级，范围为 TRACE（0）至 FATAL（5）。
[in]tag借用的非空、NUL 结尾标签；允许为空串，在调用期间有效。
[in]format借用的非空 RTT 原生格式串，在调用期间有效。
[in]...按 format 要求的顺序和类型提供格式化参数。
返回
日志提交状态，具体取值如下。
返回值
OK记录提交成功。
PENDING记录被等级过滤。
ARG_ERR日志等级非法。
PTR_NULLtag 或 format 为空。
INIT_ERR日志尚未初始化。
STATE_ERR上下文被拒绝或释放日志互斥锁失败。
BUSY日志互斥锁忙，本条记录跳过且未输出。
NO_BUFFRTT 空间不足。
NOT_SUPPORT日志已关闭。
注解
通过日志事件调用 RTT printf/vprintf，不再使用日志层行缓冲区。 函数内部仅维护一份正文参数列表，在输出结束后执行 va_end。 记录格式为“[LEVEL][tag] 正文”，末尾为 CRLF。 任务阶段用静态互斥锁串行化前缀、正文和换行；启动阶段不获取互斥锁。 获取锁不等待；释放失败优先返回 STATE_ERR，即使传输也发生错误。 过滤在参数和初始化检查之后、上下文检查之前执行。 PENDING 直接跳过记录，不入队且不改变已保存错误状态。 其他结果更新启动状态或当前任务状态；ISR 结果不会更新状态。
警告
未被过滤的写入拒绝 ISR、中断屏蔽和调度器挂起上下文。 原生 RTT 格式支持 d/u/x/X/c/s/p/%，不支持浮点和标准长度修饰符语义。 浮点数应先用 Float2StrN() 转换，再通过 s 输出。 RTT 写入和日志加锁均不等待；NO_BUFF 或释放锁失败时可能已输出部分记录。 初始化后通道 0 必须保持 SEGGER_RTT_MODE_NO_BLOCK_SKIP 模式。

◆ Float2StrN()

int Float2StrN ( char * str,
size_t size,
float va )

将有限浮点数转换为固定三位小数的字符串。

参数
[out]str借用的非空调用方缓冲区，最多接收 size 字节（包括 NUL）。
[in]size缓冲区容量，单位为字节，至少为 1，包括 NUL 结束符空间。
[in]va有限输入值，取整后的 va * 1000 位于 [-2^63, 2^63) 内。
返回
成功时返回完整结果字符数（不含 NUL）；返回值大于等于 size 表示截断。 str 为 NULL、size 为 0、输入非有限或越界、snprintf 失败时返回 -1。
注解
以 0.001 精度取整，中点向远离零方向舍入，取整后的零输出为 0.000。 size 大于 0 且 str 非 NULL 时，即使失败，缓冲区也以 NUL 结尾。 整数部分按 32 位十进制分组以支持 newlib-nano；不读取或修改日志错误状态。
警告
要求 str 指向至少 size 字节的可写缓冲区，调用上下文满足 libc 格式化要求。

缩放取整结果的边界，允许范围为 [-2^63, 2^63)。

注解
使用精确的二进制常量，避免 INT64_MAX 转为 double 后向上舍入。

< 按 FRACTION_SCALE 缩放并取整后的有符号值。

< 缩放取整结果的绝对值，单位为 1/FRACTION_SCALE。

< 拆分得到的整数部分，尚未按十进制分组。

< 小数部分的整数编码，范围为 [0, FRACTION_SCALE)。

< 负值输出 "-"；非负值及取整后的零输出空串。

< snprintf 所需字符数（不含 NUL）；负值表示格式化失败。
